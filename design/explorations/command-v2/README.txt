Planet — four command surface studies

Open index.html in a browser. Click a concept for a larger view; Show all four
returns to the comparison. Pause motion stops all edge animation. System reduced
motion preferences are respected. All UI is English and monochrome.

01 Soft halo: porcelain command field, soft corners, synchronized breathing edges.
02 Obsidian corners: smoked dark surface, corner glow, faint connecting edge light.
03 Silver current: wide slim capsule, traveling horizontal beams and vertical glow.
04 Quiet aperture: more vertical space, label plus input, inset luminous frame.

These are design proposals, not the installed Quickshell interface. Each command
field can be paired with a different concept's edge lighting. overview.png is a
browser-rendered comparison; index.html contains the actual animated CSS preview.

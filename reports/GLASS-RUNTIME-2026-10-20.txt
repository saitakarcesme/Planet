Planet dark glass / native reliability — 2026-10-20

IMPLEMENTED
  The live Quickshell overlay now uses a 720 x 62 px initial dark glass command
  field, 18 px corners, no enclosing stroke and grayscale send/stop glyphs.
  A targeted Hyprland layer rule blurs the command surface while the rest of
  the desktop remains transparent and click-through. Four narrow GPU-shaded
  strips carry a moving white/gray edge glow; hidden animation is stopped.
  The normal state remains completely invisible. No pet or conversation chain.

  planet-models.service is installed and enabled in the user's systemd manager.
  It adopts healthy models, starts the existing resident pair at login, and
  recovers after three failed health checks. It only calls the existing lab
  controller, which owns named services and refuses occupied ports or inadequate
  GPU/RAM capacity. It does not evict unrelated workloads.
  Shared inference leases prevent recovery during an active model request.
  Model-dependent requests wait with a visible starting state; deterministic
  native capabilities remain usable while models are offline.

  Literal music-search aliases now reject personal-library/playlist qualifiers
  and extra conditions. Unspecified Spotify music uses a separate semantic
  scope gate and resumes the native queue without Qwen generation.
  Named music still extracts a typed target. Unknown/qualified requests stay
  with the general planner. The three-way scope threshold (0.90) is separate
  from the 101-way capability threshold (0.97).
  Generic play opens Spotify when no player exists and requires progressing
  playback, not merely a successful input event or a static Playing flag.
  Application wildcard slots are checked against the installed catalog before
  direct execution; descriptive/polite wording goes to semantic resolution.

DEVELOPMENT FINDINGS
  Initial language trials worked but sometimes took 6–28 seconds: a reused
  confidence threshold sent the smaller scope gate to the full planner.
  The separately tested scope gate removed that unnecessary generation.
  An early independent Liked Songs oracle incorrectly looked for a Play button
  after playback. Spotify changes the row to Pause while playing. The final
  oracle checks that playing row and the actual collection ancestry.

LIMITS
  This fixes the observed lifecycle, literal-search routing and native playback
  failures. It is not a guarantee for every phrasing, account, Spotify UI version
  or arbitrary desktop task. Sign-in/network failures and unavailable controls
  still produce explicit errors. Generic tasks can take longer.
  A full cold model recovery takes about 78 seconds on this machine; ordinary
  warm commands do not load the models on every request.
  Earlier 100-capability results remain historical prepared-state measurements;
  two microphone capabilities remain unavailable without a default microphone.

  The acceptance oracle separately checked:
  - The current collection's owner matches its entry in the user's library.

  - MPRIS reports Playing for the chosen title, with a stable track ID and

ROOT CAUSES AND FIXES
  - The old native-tree reader stopped at depth 9; the relevant CEF controls
    were deeper. Bounded traversal now reaches them and retains region/table
    ancestry while excluding offscreen action targets and password fields.
  - A PyGObject interface-name collision resolved text reads to the wrong
    method. Text reads now call the explicit AT-SPI Text interface.
  - NO_AT_BRIDGE inherited from the desktop session disabled GTK accessibility.
    Planet removes it from newly launched applications.
  - Spotify requires its Chromium accessibility flag on this machine. An opt-in
    setup helper creates a local desktop-manifest override, preserving the
    packaged launcher. A normal quit/relaunch through the installed application
    catalog verified the flag and native controls. Session accessibility is on.
  - Contextual UI snapshots are compacted into bounded tables for the local
    model; older snapshots retain only small summaries. Large views can be
    inspected by label/region instead of exceeding the 16k model context.
  - The completion assessor receives initial selection context and retains the
    latest UI evidence after media polling. It must interpret "another item
    from a collection" as a different item within that collection.
  - A generic read-only media wait checks delayed playback transitions.
    A generic saved-text verifier checks actual requested file content.
  - Uppercase shortcut spelling such as Ctrl+Shift+S is normalized correctly.
    Startup focus is polled without repeatedly spawning an application.
  - Button-only accessibility trees still receive OCR supplementation, so
    custom-drawn calculator results are not lost when buttons become readable.

EXPLORATORY RECORD
  This follow-up completed 43 real-model task attempts: 34 passed their recorded
  checks and 9 did not. Earlier failures remain recorded, rather than being
  overwritten by successful reruns:
  - 3 context-overflow failures.
  - 2 step-limit failures (early music planning and the calculator readout).
  - 1 test required the planner itself to call the media wait, although the
    actual track changed. The final oracle measures progress independently.
  - 3 tests could not verify ownership because the collection header had been
    scrolled above the viewport. The final oracle reads that header directly
    from the current native accessibility page without activating hidden
    controls or changing playback. All three requests passed on rerun.

  This follow-up is separate from the historical 222-attempt baseline in
  VALIDATION-2026-10-20.txt. Unit tests and manual diagnostics are not included
  in the 43 real-model attempts.

  reliability. Other app versions, inaccessible/custom controls, logged-out
